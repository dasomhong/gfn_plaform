# FinGeo — Global Financial Network Platform

Multi-year research prototype. Source repository, published Pages website and display data: public.

Data attribution and reuse notes: [data-sources.html](data-sources.html). Source datasets retain their respective terms; no blanket data licence is granted here.

Deployment uses GitHub Actions; no analytical rebuild or dependency installation is needed.
